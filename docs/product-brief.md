# خلاصه محصول — هم‌حساب

## مسئله
در یک کلاس دبیرستان، قرض‌های کوچک نقدی بین هم‌کلاسی‌ها رایج است (ناهار، جزوه، کرایه و …). معمولاً فقط در حافظه یا چت می‌ماند؛ فراموش می‌شود، اختلاف پیش می‌آید، و هیچ تصویر روشنی از «چه کسی به چه کسی چقدر بدهکار است» وجود ندارد.

## راه‌حل
**هم‌حساب**: دفترچهٔ دیجیتال قرض داخل کلاس. پول جابه‌جا نمی‌شود؛ فقط ثبت، تأیید دوطرفه، یادآوری و تسویه پیگیری می‌شود.

## کاربر اصلی
دانش‌آموز کلاس (مثلاً پایه یازدهم) که هم قرض می‌دهد و هم قرض می‌گیرد.

## اصول تجربه
1. **ثبت سریع** — مسیر ثبت قرض در کمتر از ۳۰ ثانیه.
2. **اعتماد با تأیید** — تا وقتی طرف مقابل تأیید نکند، قرض «معلق» است.
3. **شفافیت خالص** — به‌جای لیست خام تراکنش‌ها، بدهی خالص بین دو نفر دیده شود.
4. **بدون انتقال وجه** — اپ فقط ledger است؛ وجه بیرون از اپ جابه‌جا می‌شود.

## ایدهٔ امتیازی (فراتر از حداقل تسک)

| ایده | ارزش |
|------|------|
| تأیید دوطرفه قرض | جلوگیری از ثبت اشتباه یا جعلی |
| محاسبهٔ بدهی خالص (Netting) | دو نفر با چند قرض متقابل یک عدد می‌بینند |
| بازپرداخت جزئی | بازپرداخت ۵۰ هزار از ۱۰۰ هزار |
| یادآور سررسید | نوتیفیکیشن قبل از موعد |
| کد دعوت کلاس | فقط هم‌کلاسی‌ها وارد می‌شوند |
| تقسیم هزینه (Split) | ثبت قرض گروهی برای خرید مشترک |
| گزارش ماهانه | خلاصه برای نظم مالی شخصی |

## محدودیت‌های آگاهانه
- بدون درگاه پرداخت / کیف پول
- محدود به یک کلاس (نه کل مدرسه در نسخهٔ اول)
- بدون رتبهٔ اعتباری عمومی (حریم خصوصی نوجوانان)
