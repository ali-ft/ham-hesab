# هم‌حساب — تسک طراحی تجربه و رابط کاربری مهیمن

اپلیکیشن ثبت و مدیریت قرض بین دانش‌آموزان یک کلاس (دبیرستان پسرانه شهید عباسی).  
انتقال وجه واقعی انجام نمی‌شود؛ فقط ثبت، تأیید و پیگیری مبالغ.
